# HADES Store — aplicativo nativo para PS4

O pacote instalável é gerado automaticamente pelo workflow **Build HADES Store native PS4 PKG** após alterações no projeto nativo.

Quando a compilação for concluída com sucesso, os arquivos serão publicados nesta pasta:

- [HADES-Store-PS4-v1.3.pkg](./HADES-Store-PS4-v1.3.pkg)
- [SHA256SUMS.txt](./SHA256SUMS.txt)

O pacote destina-se a consoles PS4 preparados para executar homebrew. A compilação automatizada não substitui o teste de instalação e execução no console físico.
